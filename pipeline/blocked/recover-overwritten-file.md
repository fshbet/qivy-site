You saved a new version of a document on top of the old one — this is called overwriting — and now you need the earlier copy back. Act quickly. If you use cloud storage, the older copy is probably still there.

## Check Google Drive version history

Version history is a list of older copies that Google Drive keeps automatically. Open drive.google.com. Find the file you overwrote. Open its version history and choose a version dated before the overwrite. You can then download that copy or restore it. Think of version history like a teacher keeping every draft of your essay in separate labelled folders.

1. Go to drive.google.com and sign in.
2. Find the file.
3. Open its version history.
4. Pick the version dated before the overwrite.
5. Download the file or restore it to Drive.

Reference: [See older versions of files](https://support.google.com/drive/answer/2375032)

## Check Dropbox version history

Dropbox keeps older copies of files too. Sign in to dropbox.com. Find the file. Open its version history, select the older copy, and restore it. On most personal plans Dropbox keeps versions for thirty days, but this limit can change, so check your account settings.

1. Sign in to dropbox.com.
2. Find the file.
3. Open its version history.
4. Select the older copy.
5. Click Restore.

Reference: [Restore or revert a file or folder](https://help.dropbox.com/files-folders/restore-recover-files/restore-or-revert-a-file-or-folder)

## Check Time Machine on a Mac

If the file was only on your Mac and you use Time Machine, your Mac keeps hourly backups while the backup drive is plugged in. Open Time Machine, go back to a date before you overwrote the file, select the file, and click Restore.

Reference: [Back up your Mac with Time Machine](https://support.apple.com/en-us/HT201250)

## Expected result

You will have the older copy of your file. Save it under a new name so you do not overwrite it again. If you cannot find an older copy anywhere, stop saving new files to that drive. New data can erase the space where the old file still sits. If the file matters, take the drive to a data-recovery service.
