You paste a document into a translator and get back plain text. The headings, bold words, tables and page layout disappear. You spend the rest of the afternoon fixing the look instead of checking the translation.

## Upload the whole file instead of copying text
DeepL Translator can translate PDF, Word, PowerPoint, plain text and HTML files while keeping the layout intact. Layout means where headings, images and tables sit on the page. Pasting text into the box strips out that formatting, so upload the file itself.

1. Open DeepL Translator in your browser.
2. Choose the file translation option.
3. Upload your file.
4. Pick the language the file is in now.
5. Pick the language you want it in.
6. Start the translation and download the result.

Think of it like handing someone a labelled box instead of emptying the contents into a bag. The labels stay with the box.

Expected result: You get a file in the new language. Headings, bold text, tables and page breaks stay in roughly the same places. Open it in Word, PowerPoint or your PDF reader to check.

Reference: [Document translation](https://www.deepl.com/en/pro)

## Check the limits before you start
Free accounts have file size and monthly limits. Not every language pair supports document translation. These limits change, so check DeepL's documentation before a large job.

Reference: [Document translation](https://www.deepl.com/en/pro)

## Fix the layout after downloading
If the file uses text boxes, overlapping images or unusual fonts, the layout can still shift. Open the result in Word or your PDF editor and move elements by hand. Do not paste the translation into a new plain-text file. Edit the translated file itself so the formatting stays.

Reference: [Document translation](https://www.deepl.com/en/pro)
