You pay a monthly fee for an AI assistant, but most days you only use it to write short replies or answer simple questions. The rest of what you pay for—file analysis, saved projects, web search, voice mode—sits unused. You can check your plan and try one of these features in the next ten minutes.

## Check what your subscription includes
1. Sign in to your AI assistant's website.
2. Open your account or subscription page.
3. Read the plan name and the list of features included in what you pay each month.
4. Make a note of anything you have never opened.

You are looking for tools such as file uploads, project workspaces, browsing, or advanced voice. A workspace is a saved place for your chats. If you cannot see a clear list, check the help section of the same website.

## Try saved-project chats today
Some AI assistants let you save instructions and files in one workspace. Every new chat in that workspace starts with the same background information. In Claude, this feature is called Projects, and free accounts can create a few of them while paid plans allow more. You write your instructions once, upload the files you refer to often, and then every chat in that project uses them. This is useful for regular tasks such as drafting reports, checking invoices, or editing similar documents.

Reference: [What are projects?](https://support.claude.com/en/articles/9517075-what-are-projects)

Steps to try it:
1. Open Claude and select Projects.
2. Create a new project.
3. Paste your standing instructions into the project description.
4. Upload one file you refer to regularly, such as a price list or style guide.
5. Start a chat inside that project and ask a question about the file.

## Other features you may already have
- File analysis
- Web search
- Voice mode

Pick one and use it once today. You do not need to master all of them.

## Expected result
When you open a project chat, the assistant should already know your instructions and see the files you uploaded. It should answer without you repeating the background details. If it does not, check that you are signed in and that the feature is available on your plan and in your region.

If you try a feature and do not use it again within a week, you may be paying for something you do not need. You can change or cancel your plan from the same subscription page.
