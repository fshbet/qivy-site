You type the same instructions into every AI chat. “Be concise.” “Do not apologise.” “Format as a table.” By the time you retype them, the task is half done. A prompt library is a personal list of saved prompts you copy and paste into any AI tool.

## Keep all your prompts in one place
Choose one app that works on your phone and computer. A notes app, a plain text file, or a spreadsheet all work. Think of it like a recipe book: you write the instructions once, then follow them every time.

Give each prompt a clear name so you can find it fast. “Rewrite email in British English” is better than “Prompt 1.”

## Write each prompt as a complete message
Include the role, the task, the context, and the format you want. A prompt is like giving a courier the full address, not just “deliver this.”

Example:

```
You are an editor. Rewrite the text below in British English. Keep the tone friendly. Output only the edited text. Do not add an introduction.
```

Some AI tools let you set a system prompt. That is a message that tells the AI how to behave for the whole conversation. Other tools treat every message as a user message. Both work with a paste library.

Reference: [Chat completions guide](https://platform.openai.com/docs/guides/chat-completions)

## Use brackets for parts that change
Mark anything you will swap out with square brackets. People call these placeholders. For example:

```
Summarise the article below in three bullet points. Focus on action items.

Article: [ARTICLE_TEXT]
```

Before you paste, replace [ARTICLE_TEXT] with the actual text. Brackets make the prompt reusable without rewriting it.

## Paste into any AI tool
1. Open your notes app or text file.
2. Copy the prompt you need.
3. Paste it into the AI chat box.
4. Replace any bracketed placeholders with your own text.
5. Send the message.

You do not need an extension, a plugin, or a paid plan. It works in web chats, desktop apps, and mobile apps.

If the tool has a separate box for system instructions, paste your “behaviour” prompts there. Paste task-specific prompts into the main chat box.

## Review the library once a month
Delete prompts you never used. Group the rest by task, such as writing, coding, or summarising. A small, tidy library is faster to search than a long list of forgotten experiments.

### Expected result
When you paste a saved prompt, the AI follows the instruction immediately. You stop retyping the same rules and spend more time on the work itself.
